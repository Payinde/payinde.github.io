Completed Skill Path Summary

Cyber Defense Technician Practical Path

A Level Effect Guardian Foundry learning path summary focused on practical IT foundations, systems administration, networking, Active Directory, helpdesk ticket handling, evidence review, and the Cyber Defense Technician credential.

  • Windows
  • Linux
  • Networking
  • Active Directory
  • Helpdesk
  • Evidence Review
View Verified Skill Sheet

Objective

Build practical foundations before security work by working through operating systems, networking, system administration, Active Directory, and real-world helpdesk-style ticket handling.

Coverage

The path covers Windows file systems, users and permissions, processes, services, the registry, PowerShell, CMD, Event Viewer, Linux command-line administration, TCP/IP, DNS, common protocols, and Wireshark packet analysis.

Enterprise Administration

The training includes building and administering an Active Directory domain, managing users and Group Policy, and applying hardening concepts used by IT teams and defended by SOC analysts.

Practical Validation

The Virtual HelpDesk portion uses a live-style ticket queue where user and system issues are triaged, resolved, and documented. The CDT exam validates the work through scenario-based questions built on system evidence.

Skills Demonstrated

Windows administration, Linux administration, network troubleshooting, Wireshark analysis, Active Directory administration, Group Policy awareness, helpdesk documentation, and evidence-based decision-making.

Outcome

The completed path supports my cybersecurity direction by strengthening the infrastructure, troubleshooting, and evidence-reading skills needed for SOC, IT security support, and systems administration work.
