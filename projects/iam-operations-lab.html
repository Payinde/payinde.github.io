Completed Case Study

IAM Operations & Secure Service Desk Lab

A portfolio lab connecting common helpdesk identity tasks to cybersecurity outcomes such as least privilege, access validation, and audit-ready documentation.

  • IAM
  • Entra ID
  • M365
  • Access Control
  • Documentation

Objective

Show how identity and access administration supports cybersecurity through secure account lifecycle management and documented approval processes.

Work performed

Mapped onboarding, offboarding, password resets, group membership changes, mailbox access, MFA support, and access request handling to security controls.

Skills demonstrated

Microsoft Entra ID, Microsoft 365, Active Directory, access control, ticket documentation, least privilege, and escalation handling.

Outcome

Demonstrated how service desk work can support identity security and reduce access risk when handled with proper validation and documentation.
