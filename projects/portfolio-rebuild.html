In Progress Case Study

Cybersecurity Portfolio Rebuild

A rebuild of an early front-end portfolio into a cleaner IT and cybersecurity portfolio that better communicates projects, labs, technical evidence, and career direction.

  • HTML
  • CSS
  • JavaScript
  • Responsive Design
  • Accessibility

Objective

Modernize the original portfolio so it reflects cybersecurity growth instead of only early front-end practice.

Work performed

Reworked the site structure, added project cards, case-study pages, status filters, a dark/light theme toggle, improved navigation, contact links, resume download, and animated UI elements.

Skills demonstrated

Semantic HTML, responsive CSS, accessible navigation, JavaScript interactivity, content strategy, personal branding, and documentation of technical projects.

Outcome

The portfolio became a living project that can keep growing as new cybersecurity labs, GitHub repositories, reports, and certifications are added.
