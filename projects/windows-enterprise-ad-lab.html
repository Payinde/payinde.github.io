Completed Case Study

Windows Enterprise Administration & Security Lab

A home enterprise lab focused on Active Directory, DNS, forest trusts, delegated administration, workstation authentication, and baseline security controls.

  • Active Directory
  • DNS
  • GPO
  • Windows Server
  • IAM

Objective

Build a realistic Windows domain lab to practice administration, authentication, DNS troubleshooting, access delegation, and policy enforcement.

Work performed

Configured Windows Server domain services, client workstations, user/group management, DNS records, forest trust validation, conditional forwarders, logon testing, and Group Policy controls.

Skills demonstrated

AD DS, DNS/DHCP concepts, Group Policy, Windows Server administration, PowerShell validation, access control, and troubleshooting documentation.

Outcome

Created a stronger foundation for systems administration and identity/security support by validating domain trust behavior, name resolution, logon permissions, and helpdesk delegation.
