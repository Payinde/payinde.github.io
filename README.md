# Ayinde Perouza — IT & Cybersecurity Portfolio

This is a static HTML/CSS/JavaScript portfolio focused on IT support, cybersecurity operations, DFIR labs, IAM, network analysis, and cloud security growth.

## What changed in this version

- Tighter spacing between major sections so the page feels less stretched.
- Clickable Light/Dark mode toggle with saved visitor preference using `localStorage`.
- Dark mode remains the default because it fits the cybersecurity brand, with light mode available for readability.
- Animated hero text, analyst activity feed, project filters, project status badges, and back-to-top navigation.
- Animated case-study visuals using CSS micro-interactions and motion graphics.
- Added the portfolio rebuild itself as an in-progress project.

## Updating the resume

No backend is needed. This is a static website.

To update the resume:

1. Export the latest resume as a PDF.
2. Rename it to `Ayinde_Perouza_Resume.pdf`.
3. Replace the existing file in `docs/Ayinde_Perouza_Resume.pdf`.
4. Re-upload or commit the updated site folder to your hosting platform.

If you prefer to keep dated resume versions, place the new PDF in `docs/` and update the resume links in `index.html`.

## Publishing notes

This site can be published with GitHub Pages, Netlify, Cloudflare Pages, or any basic static hosting platform.
